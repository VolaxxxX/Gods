# Music

Looping tracks, one per realm + the hub. The `Audio` autoload auto-loads
`<id>.ogg` / `.wav` / `.mp3` and loops it; silent if missing.

Expected ids (filename = id):

- `hub`     — the Threshold hub
- `greece`  — The Underworld of Hades (lyre / strings)
- `bali`    — Bali (gamelan)
- `egypt`   — The Duat (oud / ritual percussion)
- `norse`   — Helheim (cold strings / horns)
- `japan`   — Yomi (koto / taiko)
- `aztec`   — Mictlan (Andean/Mesoamerican flutes & drums)

Keep files small (Web build budget). See `/ASSETS.md`.
