# Portraits (dialogue)

Speaker portraits shown in the dialogue box. Optional (text-only if absent).
Filename = speaker id:
- `narrator.png` — the Ferryman (hub narrator)
- `<deity_id>.png` — e.g. `greece_zeus.png`, `greece_athena.png`, `egypt_ra.png`
  (deity ids are in content/<pantheon>/deities.json)

Size: ~128–256 px square, transparent or framed bust, consistent style.
