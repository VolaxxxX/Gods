# Props (decorative, non-colliding)

Transparent PNGs scattered randomly on the floor for ambience. They have NO
collision (pure decoration). A prop appears once it's:
1. dropped here as `<id>.png` (e.g. `greece_column.png`), AND
2. listed in that biome's `props` array in `content/<pantheon>/biome.json`
   (tell me the names and I add them — one line each).

Naming: `<pantheon>_<name>.png` (e.g. `egypt_urn.png`, `japan_lantern.png`).
Size: free, ~24–96 px, transparent background, top-down/3-4 view to match sprites.
