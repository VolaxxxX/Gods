# UI textures (all optional — the UI is themed and works without them)

9-slice frames: design so the border (= margin) stays fixed and the centre
stretches. Transparent PNG. Drop a file and it replaces the flat default.

- panel.png        96x96, 9-slice margin 24  -> all windows/panels (dialogue boon, pause)
- button.png       64x64, 9-slice margin 16  -> button (normal)
- button_hover.png 64x64, 9-slice margin 16  -> button (hover)
- button_pressed.png 64x64, 9-slice margin 16 -> button (pressed, optional)
- bar_bg.png       48x24, 9-slice margin 6   -> health bar background
- bar_fill.png     48x24, 9-slice margin 6   -> health bar fill (the coloured part)
- dialogue.png     128x96, 9-slice margin 28 -> dedicated dialogue frame (else panel.png)
- coin.png         24x24, no 9-slice         -> gold icon in the HUD
